# MP-Gateway-Plugins

**MP-Gateway – Das Multiprotokoll-Gateway**

MP-Gateway verbindet unterschiedliche Smart-Home-, Gebäudeautomations- und IoT-Systeme über eine gemeinsame Objekt- und Routing-Ebene.
